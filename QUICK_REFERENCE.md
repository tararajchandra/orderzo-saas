## 👤 Customer Quick Tasks

### 🛒 Place an Order (3 Steps)
```
1. Browse Menu → /menu
2. Add items to cart → Click "Add to Cart"
3. Checkout → /checkout → Fill details → Place Order
```

### 📦 Track Order
```
Go to /orders → Enter phone/email → View status
```

### 🔍 Search Menu
```
Menu page → Search bar → Type item name
```

---

## 👨‍💼 Admin Quick Tasks

### ➕ Add Menu Item
```
Admin → Menu → Add New Item → Fill form → Upload image → Save
```

### 📝 Update Order Status
```
Admin → Orders → Select order → Change status → Update
```

### 🚚 Assign Delivery Boy
```
Admin → Orders → Order details → Select delivery boy → Assign
```

### 📄 Generate Invoice
```
Admin → Invoices → Select order → Generate Invoice → Download/Print
```

### 📊 View Reports
```
Admin → Analytics/GST Report → Select date range → Generate
```

### 💾 Backup Data
```
Admin → Data Management → Export Data → Select types → Download
```

---

## 🚚 Delivery Boy Quick Tasks

### 📋 View Assigned Orders
```
Login → Dashboard → Pending Deliveries
```

### ✅ Mark as Delivered
```
Dashboard → Select order → Mark as Delivered → Confirm
```

### 💰 Check Earnings
```
Dashboard → Today's Earnings / Payouts section
```

## 💼 Salesman Quick Tasks


### 📊 View Performance

```
Dashboard → Sales Dashboard → View stats
```

## 🎯 Common Workflows

### Customer Order Flow
```
Browse Menu → Add to Cart → Checkout → Enter Details 
→ Select Payment → Place Order → Track Status
```

### Admin Order Processing
```
Receive Order → Confirm → Prepare → Assign Delivery 
→ Out for Delivery → Mark Delivered → Generate Invoice
```

### Delivery Flow
```
Receive Assignment → Pick Up Order → Contact Customer 
→ Deliver → Mark as Delivered → Collect Payment (if COD)
```

### Salesman Order Flow
```
Meet Customer → Create Order → Select Items → Enter Details 
→ Submit → Follow Up → Track Commission
```
